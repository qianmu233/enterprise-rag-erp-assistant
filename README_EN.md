# Spring AI RAG Demo — independent safe source snapshot

This is an Apache-2.0 derivative of [ly1836/spring-ai-rag-demo](https://github.com/ly1836/spring-ai-rag-demo), upstream baseline `b0bd1fd571e57e4943b5768a41bef0dba86852b3` (4.0.0). Its existing RAG, ERP tools, conversation management and chart foundations are not claimed as new downstream inventions.

Downstream work includes the optional Java/Python model gateway, output handling, model protocol contracts, and bounded quality diagnostics. The snapshot uses reviewed publication-main contents at `3efdbd00840f5f168437c5a77244b97a98368555` but starts a completely new Git root. It contains no old Git directory or branches, real environment files, original business records, upstream screenshots/GIFs, chat logs, or development test-data. New seed records and contact labels are explicitly synthetic and non-dialable.

The fixed Apache-2.0 multilingual MiniLM ONNX and tokenizer are stored through Git LFS; frontend libraries retain their applicable Apache-2.0, MIT and BSD notices. See [third-party resources](docs/third-party-resources.md), [NOTICE](NOTICE), [snapshot audit](docs/SAFE_SNAPSHOT_AUDIT.md), and the [Chinese README](README.md) for exact scope and commands.

Real historical RAG evaluations still show over-refusal and incomplete evidence coverage. Offline retrieval reconstruction is not a real-model quality improvement. The separate previous-sentence expansion experiment is excluded. This project is an engineering demonstration, not a production reliability or security claim.
