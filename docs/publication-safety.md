# 新快照的公开与部署边界

本轮只建立独立本地源代码快照。旧 Private GitHub 仓库、原开发历史和旧发布历史保持原样；新根不意味着旧疑似凭据已撤销，也不消除旧服务中的数据或平台附件。

仅配置名称和明确测试占位符可以进入源代码。真实环境文件、API Key、数据库密码、私钥、运行 JSON、日志、虚拟环境、缓存和数据库不进入 Git。两项固定模型为唯一通过 LFS 分发的模型资源，不附加其他权重。

运行时数据库密码必须由环境注入；Provider 占位符与 Gateway 公开测试令牌均非可对外部署的凭据。Compose 的应用和数据库端口保持 loopback。源码中没有为新快照新增身份认证，因此租户 Header 不能当作可信身份；ERP 工具和动态 SQL 不是生产零信任安全网关。

截图、GIF 与非必要第三方图片全部排除；必要浏览器 JS/CSS 和模型分别保留适用许可。Maven/Python 依赖只声明坐标/版本，不将缓存或打包 JAR 作为本次源码制品提交；未来若分发 JAR/容器，应另查全部传递依赖及其分发义务。

专用扫描、离线构建、测试、已知失败和未验证范围见 [本次审计](SAFE_SNAPSHOT_AUDIT.md)。扫描无命中不能证明不存在任何隐私，历史真实 RAG 质量限制也不会因新 Git 根而改变。
